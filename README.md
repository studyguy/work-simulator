# 🏢 打工模拟器（Work Simulator）

> 参照「人生重开模拟器」玩法的**文字类职场生涯模拟游戏** —— 从 22 岁大学毕业到退休（或中途淘汰），一路随机事件、属性涨跌、无厘头职场梗，手机 / PC 双端可玩。

**[🎮 在线游玩](https://studyguy.github.io/work-simulator/)** · **[📦 源码仓库](https://github.com/studyguy/work-simulator)**

---

## 🕹️ 这是什么

你从 22 岁大学毕业开始进入职场，直到退休（或中途被淘汰）。每一年都会触发随机事件，影响你的属性、月薪和存款——合理分配初始属性、选择合适的天赋，争取最好的职场结局。

剧情取材真实职场生活：面试、加班、跳槽、租房、买房、互联网寒冬、AI 冲击……既有接地气的搞笑梗，也有扎心的现实映射。130+ 事件、30+ 天赋、10+ 结局，配合「发际线」这种程序员特色属性，每次开局都是一场新的打工人生。

纯前端静态页面，**双击 `index.html` 即可游玩**，localStorage 自动存档。

## ✨ 核心玩法

1. **选择学历背景** —— 影响初始属性
2. **抽取天赋（10 选 3）** —— 天赋决定你的特殊能力
3. **分配属性点** —— 编程能力、沟通能力、体力精力、家境背景
4. **开始打工生涯** —— 点击「下一年」推进时间，触发各种职场事件
5. **达成结局** —— 正常退休、财务自由、中年危机等 10+ 种结局

### 核心属性

| 属性 | 说明 |
|------|------|
| 💻 编程能力 (COD) | 写代码水平，影响技术类事件 |
| 🗣️ 沟通能力 (COM) | 表达能力，影响面试、升职 |
| 💪 体力精力 (STA) | 抗压能力，影响加班和健康 |
| 🏠 家境背景 (FAM) | 经济条件和人脉资源 |
| 😊 快乐值 (HAP) | 心理健康，过低会触发负面事件 |
| 💇 发际线 (HRL) | 程序员特色属性！越秃越强 |

### 结局一览

| 结局 | 触发条件 |
|------|---------|
| 🏆 财务自由 | 存款 > 500w |
| 🎂 正常退休 | 年龄 ≥ 65 岁 |
| 😢 中年危机 | 30 岁 + 存款不足 + 快乐低 |
| 🏠 躺平人生 | 快乐值持续为 0 |
| 🧠 出家修行 | 发际线归零 |
| 🎭 职场成神 | 等级达到 Lv.10 |
| 🚀 创业成功 / 💼 被裁员 / 💀 特别结局 | 特殊事件与隐藏彩蛋触发 |

## 🛠️ 技术实现

- **纯前端**：Vanilla JS + 原生 DOM 操作，无框架、无构建
- **深色像素风 CSS**，移动端优先响应式设计
- **localStorage 存档**，跨会话保留进度
- **条件解析引擎**（`utils/condition.js`）驱动 130+ 事件的触发条件
- **事件内容分类**：职场事件 20+ / 奇葩搞笑事件 20+ / 生活事件 10+ / 时代背景事件 10+
