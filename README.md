# 🏢 打工模拟器 (Work Simulator)

参照"人生重开模拟器"玩法，打造的一款文字类职场生涯模拟游戏。
蕴含丰富无厘头剧情和接地气的职场搞笑元素。

## 玩法简介

你从 22 岁大学毕业开始，进入职场打拼，直到退休（或中途淘汰）。
每一年都会触发随机事件，影响你的属性、月薪和存款。
合理分配初始属性，选择合适的天赋，争取最好的职场结局！

### 游戏流程

1. **选择学历背景** - 影响初始属性
2. **抽取天赋（10 选 3）** - 天赋决定你的特殊能力
3. **分配属性点** - 编程能力、沟通能力、体力精力、家境背景
4. **开始打工生涯** - 点击"下一年"推进时间，触发各种职场事件
5. **达成结局** - 正常退休、财务自由、中年危机等 10+ 种结局

## 核心属性

| 属性 | 说明 |
|------|------|
| 💻 编程能力 (COD) | 写代码水平，影响技术类事件 |
| 🗣️ 沟通能力 (COM) | 表达能力，影响面试、升职 |
| 💪 体力精力 (STA) | 抗压能力，影响加班和健康 |
| 🏠 家境背景 (FAM) | 经济条件和人脉资源 |
| 😊 快乐值 (HAP) | 心理健康，过低会触发负面事件 |
| 💇 发际线 (HRL) | 程序员特色属性！越秃越强 |

## 技术栈

- 纯前端静态页面（Vanilla JS）
- 原生 DOM 操作，无需框架
- CSS 深色像素风格
- localStorage 存档
- 移动端优先，响应式设计

## 如何运行

### 方式一：直接打开

用浏览器打开 `index.html` 即可运行（建议使用现代浏览器）。

### 方式二：本地服务器

```bash
# Python 3
cd work-simulator
python3 -m http.server 8000

# 或 Node.js
npx serve .
```

然后访问 `http://localhost:8000`。
